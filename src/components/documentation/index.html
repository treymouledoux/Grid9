Basic Description

In one sentence: Grid9 is an esoteric interpreted language made in Nim (and now rewritten in Rust) based on a 3×3 grid of cells — nine cells total — where each cell holds a zero or a one.

You interact with these cells by setting them (s), flipping them (f), or setting all cells to a value (a). Every output-able character in the language has its own unique combination of cells. Why nine cells and not eight, the size of a byte? There's no strict reason — but the ninth cell is useful for variable storage, holding a zero or one that can sway your logic.

The language doesn't stop at changing a few numbers; there are statements, control-flow operators, and more.

Cell Modification

Sets<cell><value>

The set command sets a cell to a value.

The syntax is s followed by the cell id and then the value you want to set it to. Unlike flip, set writes a cell's value with certainty.

For example, to set cell 0 to 1 you would run the code below.

grid9
s01

Flipf<cell>

The flip command flips a cell to the opposite value.

The syntax is f followed by the cell id you'd like to flip (0–8). Unlike set, flip toggles the value regardless of what it currently is.

For example, to flip cell 2 you would run the code below.

grid9
f2

Set-alla<value>

The set-all command sets every cell to a single value at once.

The syntax is a followed by the value you want every cell to take.

For example, to give all cells the value 1 you would run the code below.

grid9
a1

02

IO

Printp

The print command prints the grid's glyph character to the console.

Every output-able character has a combination on the grid called a “glyph.” Print converts the current glyph into the single character it represents. If the queue contains anything, print outputs the queue instead of the current glyph. The syntax is p.

For example, the character “a” is represented by 000000010. Flip cell 7 (cell ids start at 0) and print, and it outputs “a,” as shown below.

grid9
f7 p

Queueqs / qc

The queue command prints multiple glyphs or characters together.

The syntax is qs to add a glyph to the queue and qc to clear the queue entirely.

Say you want to print two “r” letters side by side. Build the glyph for “r,” save it to the queue, build it again, save it, then print — giving you “rr,” as shown below.

grid9
f4 f7 f8 qs a0 f4 f7 f8 qs p

03

Logic

Ifi<cell>=/!<value> … }

The if command checks whether a cell is a zero or a one.

The syntax is i followed by the cell id, then = (equal) or ! (not equal), then the value you're testing for. Close an if statement with }.

For example, to test cell 2 for zero and, if true, print the letter c, run the code below.

grid9
i2=0 f6 p }

Whilew<cell>=/!<value> … ]

The while command loops as long as its condition is met.

The syntax mirrors if: w followed by the cell id, then = or !, then the value you're testing for. Close a while statement with ].

For example, to loop while cell 2 is zero, printing the letter c infinitely, run the code below.

grid9
w2=0 f6 p ]

Exite

The exit command breaks out of the current while loop.

The syntax is simply e.

For example, to loop while cell 5 is zero, print the letter c, then break out of the loop, run the code below.

grid9
w5=0 f6 p e ]

04

Grid

Givegg

The give command lets users supply a glyph pattern as input to the script.

The syntax is gg.

For example, a simple glyph-to-character converter takes input and prints the character as output. The code for that is shown below.

grid9
gg p

Save and Loadgs<id> / gl<id>

Save and load commands store and recall glyph patterns to other grids for use later.

The syntax is gs plus an id from 0–8 to save, and gl plus an id from 0–8 to load.

grid9
ar s00 p gs0 ar s00 p gl0 p

Maskgm<id>

The mask command masks a saved grid on top of the current grid.

The syntax is gm plus an id from 0–8 to mask.

grid9
ar gs0 ar gm0

Xorgx<id>/c

The xor command xors the current grid, or a saved grid, against it.

The syntax is gx plus an id from 0–8, or c to xor against the current grid.

grid9
f6 f2 f0 f7 gxc

05

Misc

Backb<n>

The back command jumps back to previous instructions in the code.

The syntax is b followed by the number of instructions to go back. This value can be any number greater than 0.

For example, to go back 23 instructions you would run the code below.

grid9
b23

Delayd<seconds>

The delay command waits between instructions in your code.

The syntax is d followed by the number of seconds to wait before continuing. This value can be any number greater than 0.

For example, to flip a value, wait 14 whole seconds, then print it, run the code below.

grid9
f6 d14 p

Terminatet

The terminate command ends the program.

The syntax is simply t.

For example, to terminate the program when a condition is met, use the code below. The f7p at the end never runs: by default all cells are 0, so the condition is true and the program terminates first.

grid9
i0=0 t } f7 p

06

Config

Tomlconfig.toml

Grid9 can be configured with a TOML file that changes how your code runs. The Rust rewrite (v2026.1.0 and above) uses snake_case keys split across a [metadata] table and a [config] table.

The structure is shown below. Any value you leave out falls back to its default; the rest take the values you define.

config.toml
[metadata]
author        = "unknown"
description   = "empty"
version       = "0.1.0"
min_grid9_ver = "2026.1.0"
show_metadata = false

[config]
advanced_parse = true
dont_cache     = false
echo_grid_mod  = false
no_log         = false
verbosity      = 1

These options change how Grid9 interacts with your code. For instance, advanced_parse makes the program start slower but can fix issues in your code, and echo_grid_mod prints the grid after every instruction that modifies a cell, which is handy for seeing more technical detail while debugging.
